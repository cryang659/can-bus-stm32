# CAN 总线练习工程（STM32F103C8T6）

基于标准外设库 V3.5 的空工程修改，**不碰任何交付固件**。
目标：两天内跑通「回环 → 双节点 → 波形 → 错误状态」，能当场答出 CAN 细节。

---

## 一、硬件

| 件 | 数量 | 说明 |
|---|---|---|
| STM32F103C8T6 最小系统板 | 1 | 单板回环只需这一块 |
| CAN 收发器 TJA1050 或 SN65HVD230 | 1（单板）/ 2（双节点） | 控制器 ≠ 收发器，必须有 |
| 120Ω 电阻 | 2（双节点） | 接在总线**两端** CAN_H–CAN_L 之间 |
| USB-TTL（CH340） | 1 | 看 USART1 打印，115200 |

---

## 二、接线

| STM32 | 收发器模块 | 说明 |
|---|---|---|
| PA11（CAN_RX） | RX / CRX | MCU 收，模块的发 |
| PA12（CAN_TX） | TX / CTX | MCU 发，模块的收 |
| 5V（TJA1050）或 3.3V（SN65HVD230） | VCC | 电压别接错 |
| GND | GND | **必须共地** |

双节点：

```
节点A ────┬──── CAN_H ────────────┬──── 节点B
          │                       │
         120Ω                    120Ω
          │                       │
          └──── CAN_L ────────────┘
              （GND 也要互联）
```

USART1：PA9 → USB-TTL 的 RX，PA10 → USB-TTL 的 TX，GND 共地。

> ⚠️ PA11/PA12 也是 USB_DM/DP。最小系统板如果插着 USB，先拔掉，用 ST-Link 供电。
> ⚠️ 自制载板只引出了 PB13/PB15/PC9，PA11/PA12 可能不在排针上——用最小系统板，别用载板。

## 三、位定时（500 kbps）

系统 72MHz → APB1 36MHz：

```
Prescaler = 9   → Tq = 9/36MHz = 250ns
1 位 = SYNC(1) + BS1(6) + BS2(1) = 8 Tq
8 × 250ns = 2µs → 500 kbps
采样点 = (1+6)/8 = 87.5%
```

代码里在 `main.c` 顶部：

```c
#define CAN_PRESCALER   9
#define CAN_BS1         CAN_BS1_6tq
#define CAN_BS2         CAN_BS2_1tq
```

## 四、两种模式

`main.c` 第 26 行：

```c
#define CAN_WORK_MODE   CAN_Mode_LoopBack   // 单板自测
// #define CAN_WORK_MODE   CAN_Mode_Normal  // 双节点
```

### 第 1 步：回环自测（不需要收发器）

烧进去，串口应看到：

```
===== CAN demo (STM32F103C8, 500kbps) =====
[BOOT] SystemCoreClock=72000000
[CAN ] mode=LoopBack (self-test, no transceiver needed)
[CAN ] init OK, filter=accept-all, IRQ=RX0
[TX  ] id=0x123 cnt=0 tx=1 rx=1
[RX  ] id=0x123 dlc=8 data=00 00 00 00 AA 55 01 01
```

TX 和 RX 交替出现，`rx` 计数跟着涨，说明初始化、位定时、滤波器、收发全对。

**不通**：问题在纯软件，跟硬件无关。先查 `CAN_Init` 返回值、滤波器、中断向量。

### 第 2 步：双节点

两块板都改成 `CAN_Mode_Normal`，接好收发器和 120Ω。A 每 500ms 发，B 的串口打印 `[RX]`。

现象不对，按这个顺序查：

1. 两边波特率是否一致
2. 120Ω 有没有接、是不是在**两端**
3. CAN_H / CAN_L 有没有接反（TJA1050 反接收不到）
4. 有没有共地
5. 收发器 VCC 对不对（TJA1050 必须 5V）

### 第 3 步：示波器量波形

- CAN_H 单端：隐性 ≈2.5V，显性 ≈3.5V
- CAN_H − CAN_L 差分：隐性 ≈0V，显性 ≈2V
- 量一位宽度：500kbps 下应为 **2µs**

### 第 4 步：故意制造错误（面试加分）

拔掉另一个节点 → 发送收不到 ACK → 自动重发 → TEC 上涨 → 最终 Bus-Off。
串口 `[ERR ]` 行能看到 `tec` 变化。这一条能把 CAN 的错误管理讲透。

## 五、常见问题

| 现象 | 原因 |
|---|---|
| 回环都不通 | 位定时 / 滤波器 / 中断向量配错 |
| 发送一直 FAIL | 没接收发器、120Ω 缺失、CAN_H/L 反接、没共地 |
| 一接上就 Bus-Off | 两边波特率不一致 |
| 串口乱码 | 晶振不是 8MHz，或波特率不对 |
| 回环 OK，双节点不通 | 硬件问题（线序、终端电阻、供电） |

## 六、面试 10 问（做完这些就能答）

1. CAN 和 UART/RS485 的区别？→ 差分、多主、非破坏性仲裁、硬件 CRC、广播 + 验收滤波
2. 为什么 120Ω？→ 匹配特征阻抗，消反射
3. 位定时怎么算？采样点为什么 87.5%？→ 见第三节
4. 标准数据帧有哪些场？→ SOF / 仲裁场 / 控制场 / 数据场 / CRC 场 / ACK 场 / EOF
5. 位填充是什么？→ 连续 5 个相同电平插 1 个相反位
6. 仲裁为什么不丢数据？→ 显性覆盖隐性，输的节点立刻转接收
7. 滤波器两种模式？→ 掩码 / 列表；32 位 / 16 位
8. TEC/REC 三种错误状态？→ 错误主动 → 错误被动 → Bus-Off
9. 回环模式干嘛用？→ 隔离软硬件问题
10. 经典 CAN vs CAN FD？→ 8 字节/1Mbps vs 64 字节/数据段 5Mbps+
